# NEXUS: Guardian

Keeps an eye on the live `UObject` count. When it climbs past a baseline, Guardian warns, snapshots, and diffs, so leaks announce themselves. Kept out of Shipping by default.

- **Documentation:** https://nexus-framework.com/docs/guardian/
- **Modules:** `NexusGuardian` (Runtime), `NexusGuardianEditor` (Editor)
- **Requires:** `NexusCore`, `NexusTooling`, `NexusUI`, `CommonUI`

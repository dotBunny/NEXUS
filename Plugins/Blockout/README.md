# NEXUS: Blockout

Content for blocking out a level: walls, parapets, barriers, stairs and primitives sized in round numbers, plus grid, debug, metal and lighting-guide materials. Almost entirely content: its one module only boots the plugin.

- **Documentation:** https://nexus-framework.com/docs/blockout/
- **Modules:** `NexusBlockout` (Runtime)
- **Requires:** `NexusCore`

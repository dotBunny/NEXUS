# NEXUS: Dynamic References

A service locator for actors. Register actors under a reference and look up everything registered there, with no hard dependencies between them.

- **Documentation:** https://nexus-framework.com/docs/dynamic-references/
- **Modules:** `NexusDynamicRefs` (Runtime), `NexusDynamicRefsEditor` (Editor)
- **Requires:** `NexusCore`, `NexusTooling`, `NexusUI`

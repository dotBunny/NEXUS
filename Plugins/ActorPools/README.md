# NEXUS: Actor Pools

Pool actors instead of spawning and destroying them: pools you can prewarm, spawner components, kill zones that return actors, and Blueprint async actions for getting and spawning.

- **Documentation:** https://nexus-framework.com/docs/actor-pools/
- **Modules:** `NexusActorPools` (Runtime), `NexusActorPoolsEditor` (Editor)
- **Requires:** `NexusCore`, `NexusPicker`, `NexusTooling`, `NexusUI`, `CommonUI`, `EditorScriptingUtilities`

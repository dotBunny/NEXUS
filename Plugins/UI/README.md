# NEXUS: UI

UMG and CommonUI components and helpers: list views and entries, widgets that update without firing their own events, developer overlays, game user settings helpers, and safe streaming of 3D text.

- **Documentation:** https://nexus-framework.com/docs/ui/
- **Modules:** `NexusUI` (Runtime), `NexusUIEditor` (Editor)
- **Requires:** `NexusCore`, `CommonUI`

# NEXUS: Tooling

Editor-only quality-of-life: Texture Packer, Multiplayer Test, Selection Lock, asset validators, Find & Fix, a collision visualizer, leak checks and more. Never cooked into a game.

- **Documentation:** https://nexus-framework.com/docs/tooling/
- **Modules:** `NexusToolingEditor` (Editor)
- **Requires:** `NexusCore`, `NexusUI`, `CommonUI`

# NEXUS: World Assembly

Procedural level assembly from hand-authored cells. Author cells with junctions, group them into tissues, and let organs assemble them deterministically, with baked world collision and multiplayer-aware streaming. Early Access.

- **Documentation:** https://nexus-framework.com/docs/world-assembly/
- **Modules:** `NexusWorldAssembly` (Runtime), `NexusWorldAssemblyEditor` (Editor)
- **Requires:** `NexusCore`, `NexusPicker`, `NexusTooling`, `NexusUI`, `CommonUI`, `EditorScriptingUtilities`, `PCG`

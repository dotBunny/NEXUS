# NEXUS: Picker

Generates points in and on shapes (circle, arc, rectangle, box, oriented box, sphere, spline), optionally projected onto collision or the navmesh, with seeded determinism.

- **Documentation:** https://nexus-framework.com/docs/picker/
- **Modules:** `NexusPicker` (Runtime), `NexusPickerEditor` (Editor)
- **Requires:** `NexusCore`

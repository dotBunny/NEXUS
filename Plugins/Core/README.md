# NEXUS: Core

The foundation every other NEXUS plugin builds on: seeded random and ranges, collections, actor and level utilities, raw-mesh tools, developer reports and object snapshots, and PCG elements.

- **Documentation:** https://nexus-framework.com/docs/core/
- **Modules:** `NexusCore` (Runtime), `NexusCoreEditor` (Editor)
- **Requires:** `DataValidation`, `MeshModelingToolset`, `PCG`
